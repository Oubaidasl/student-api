# Rapport du Projet Student API

## Introduction

Ce projet consiste à développer une API REST de gestion des étudiants avec Flask.

L'objectif est d'appliquer les concepts de :

- développement backend
- Git/GitHub
- méthodologie Agile
- DevOps

---

## Objectifs du projet

- Créer une API REST fonctionnelle
- Gérer des étudiants
- Utiliser GitHub pour le travail collaboratif
- Utiliser ZenHub pour la gestion Agile
- Préparer le projet pour Docker et Jenkins

---

## Technologies utilisées

### Python

Utilisé pour développer l'API.

### Flask

Framework backend léger pour les APIs REST.

### Langage C

Utilisé pour l'algorithme de tri des étudiants.

### GitHub

Gestion du versioning et collaboration.

### ZenHub

Gestion des tâches et organisation des sprints.

## Fonctionnalités

### API REST

- Affichage des étudiants
- Recherche par ID
- Ajout d'étudiants

### Algorithme C

Tri des étudiants par note.

### Tests unitaires

Validation des routes de l'API.
