# Workflow GitHub

## Branches utilisées

- main
- develop
- feature/api-flask
- feature/tests-docs

---

## Méthode de travail

1. Création d'une branche feature/*
2. Développement de la fonctionnalité
3. Commit des modifications
4. Push vers GitHub
5. Création d'une Pull Request
6. Merge vers develop

---

## Organisation Agile

Le projet est organisé avec :

- GitHub
- ZenHub
- Issues
- Sprints
- Kanban Board

---

## Collaboration

Chaque membre travaille sur une branche séparée afin d'éviter les conflits.
