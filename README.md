# Student API Project

## Description

Cette application est une API REST développée avec Flask pour gérer des étudiants.

Le projet permet :

- d'ajouter des étudiants
- d'afficher la liste des étudiants
- de rechercher un étudiant par ID
- de trier les étudiants par note

---

## Technologies utilisées

- Python
- Flask
- C
- GitHub
- ZenHub
